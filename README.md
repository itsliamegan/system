# System Configuration

This repository contains system configuration files as well as scripts for
setting up a new system. These files are designed to work on Debian (unstable)
to configure XFCE, Firefox, Emacs, Bash, and other tools for a development
environment. Each directory contains files for a specific tool or set of tools.

The `setup` script installs packages and sets up symlinks. Run it without
arguments to print usage information.
